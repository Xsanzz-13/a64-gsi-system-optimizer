# XSANZZ OS GApps status

Selected preference: LiteGapps **Lite** variant, ARM32.

The current LiteGapps website states that ARM32 support is no longer available for Android 16 and later. A SourceForge archive named `LiteGapps-arm-16.0-20261001-official.zip` exists (203.2 MB; SHA-256 `702c5d2d6240cc7478360f61788ae68f5b70378b1ea6889bd6f5afefa78a0d1f`), but archive availability does not override the current support statement.

For that reason, this build does not inject or repackage the archived LiteGapps package. Do not assume that it is compatible merely because it is labelled ARM / Android 16. A compatible ARM32 Android 16 package must be selected and validated before bundling.

Official references:
- https://litegapps.github.io/
- https://litegapps.github.io/doc/installation.html
