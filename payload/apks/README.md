XSANZZ OS bundled applications

The build pipeline embeds these supplied APKs into /system/app:
- Brevent — me.piebridge.brevent
- ZArchiver Pro — ru.zdevs.zarchiver.pro

The APK binaries are supplied as the XSANZZ_APK_EXPORT_LITE.zip build input and are not committed to this source tree.
Chrome is not included.
